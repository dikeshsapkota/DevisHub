# 🌌 Overview

**DevHub** is a next-generation social platform built specifically for developers, software engineers, students, and open-source contributors.

It combines the best aspects of professional networking, project showcasing, technical documentation, and developer collaboration into a single platform with a unique **Neo-Futurism** design language.

Users can create professional profiles, publish development updates, showcase projects, write Markdown documentation, connect with developers worldwide, and communicate through real-time messaging.

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/yourusername/devhub.git

cd devhub
```

---

## Install Frontend

```bash
cd client
npm install
```

---

## Install Backend

```bash
cd ../server
npm install
```

---

## Configure Environment

Create:

```text
client/.env
```

```env
VITE_API_URL=
VITE_GOOGLE_CLIENT_ID=
VITE_GITHUB_CLIENT_ID=
```

Create:

```text
server/.env
```

```env
DATABASE_URL=
JWT_SECRET=

GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET=

GITHUB_CLIENT_ID=
GITHUB_CLIENT_SECRET=

CLOUDINARY_CLOUD_NAME=
CLOUDINARY_API_KEY=
CLOUDINARY_API_SECRET=
```

---

## Prisma

```bash
npx prisma generate

npx prisma migrate dev
```

---

## Start Backend

```bash
npm run dev
```

---

## Start Frontend

```bash
npm run dev
```
